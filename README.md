# Estrada Livre — Locadora de Veículos

**Integrantes:** Lucas Goulart e Enzo Marques

## Como executar

A partir da pasta `EstradaLivre`, compile os arquivos:

```bash
javac model/*.java app/*.java
```

Depois execute:

```bash
java app.TesteLocadora
```
